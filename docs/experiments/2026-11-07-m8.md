## Independent verifier change

`p.launchd_running` now checks PID 1, `/sbin/launchd`, and
`XNU.load_init_program`. `p.daemon_spawned` requires a later integer PID > 1,
a non-launchd name, and `XNU.__mac_execve` in the same log. The two witnesses
come from the same qualifying log. The old PID-1 self-report, records split
across boots, and reversed ordering fail the controlled checks; a valid pair
passes. M8 implementation metadata now records CODE COMPLETE.

HostView also prunes `.scratch`. Test manifests and guest logs there previously
entered the real host scan; a fixture-driven M0 PASS then failed the runner's
required-scope validation. The added regression keeps a real sibling log
discoverable while excluding the scratch log. No genuine guest logs were removed.
