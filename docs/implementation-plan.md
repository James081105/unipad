## 判定规则

- CODE COMPLETE ≠ 现场 PASS；SIMULATION PASS ≠ 现场 PASS。
- 现场（用户 Windows 本机启动 iPadOS）未执行前一律 UNVERIFIED/BLOCKED，并在最终报告列明。
- 任何「成功」必须有证据：实验记录 + 产物哈希 + 运行日志 + 验证器结论；证据缺失即未验证。
